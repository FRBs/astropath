# Mermaid Diagram

## Goals

This document is a guide for creating a mermaid diagram of the PATH calculations.

## Coding

Here are guidelines for coding: 

- Examine the work described in the speed_up_fixed.md document.
- Use Python where possible
- Add inline comments to explain the effort
- Reuse existing code when possible, especially in bayesian.py and localization.py
- Place import statements at the top of the file.
- Include a description of inputs/outputs in the doc string of all methods
- Use lines of code that are less than 80 characters wide
- Add "Generated by JXP and Claude" in the doc string of all methods you create

If you need to run python, use the "astro14" environment.

**What I examined** to map the calculation flow accurately:

- `astropath/priors.py` — `raw_prior_Oi`, `renorm_priors`.

**Deliverable:** `docs/path_calculation_diagram.md` — a portable
Markdown page containing a Mermaid `flowchart TD` with subgraphs for
Setup, Candidate priors P(O_i), Likelihood p(x|O_i) (fixed vs local,
calc_LWx, the per-candidate θ → pw_Oi → product → sum loop, and the
optional numba path), the unseen term p(x|U), the evidence p(x), and the
posteriors P(O_i|x) / P(U|x). Each box is annotated with its module and
function, and the prose below the diagram links to the source files and
`performance.rst`.

renders on GitHub and in the IDE without adding a Sphinx dependency. If
you'd prefer it built into the Sphinx HTML site, I can instead add
`sphinxcontrib-mermaid` to `extensions` + `requirements.txt` and convert
the page to RST, then link it from `docs/index.rst` — see the question
